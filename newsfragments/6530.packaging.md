On Windows, `pyo3-ffi` now auto-detects the Python shared library name at build time and generates the `#[link(..., kind = "raw-dylib")]` attribute dynamically, instead of enumerating all known library names (`python39`..`python316`, `libpypy3.11-c`, etc.) in the `extern_libpython!` macro. This means any Python version or implementation — including future ones — is supported without source changes, and import libraries (`.lib` files) are no longer required.
